# Folder-Nester
Folder nester is (in my opinion) the quickest way make a bunch of folders with each inside of the last where ever you want!

## How it works
Basically it will give you prompt on if where you want to have the folders created (You can also press enter without typing any thing if you want the current location of the file to be where the folders are created)
after that it will let you select how many folders you want nested and what you want to name your folders.

## How to Download the files and open them
To download Folder-Nester click on the Green code button above and look until you see Download .zip, after that it will go to C:\Users\YourUser\Downloads (your downloads folder). Then extract the .zip file. Now open your Command Prompt (Start + R then type cmd) and navigate to your Downloads folder 
```bash
cd Downloads
```
Then type
 ```bash
cd Folder-Nester/Folder-Nester
``` 
and Finally type 
```bash
node Folder-Nester.js
```
If done correctly you should see "--- Nested Folder Creator ---" Before seeing "Where should we build this? (Press Enter for current directory): " And that it! You have successfully opened Folder-Nester on your PC. Now Go Nest Away!
