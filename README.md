# Folder-Nester
Folder nester is (in my opinion) the quickest way make a bunch of folders with each inside of the last where ever you want!

## How it works
Basically it will give you prompt on if where you want to have the folders created (You can also press enter without typing any thing if you want the current location of the file to be where the folders are created)
after that it will let you select how many folders you want nested and what you want to name your folders.
